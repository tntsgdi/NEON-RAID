# 设计定案（2026-10-19 grilling）

源文档：Google Drive《霓虹行者 / NEON RAID》2.0。原文由多段对话拼成、前后有矛盾，以本文件为准。

## 作品身份
- 中文《霓虹行者》，英文 **NEON RAID**（不用 NEON RUNNER）。
- 主角 **R-0**：700 年前旧文明的意识转移原型机；现代机器人协议沿用了它的底层，所以能夺壳。
  "企业控制程序逃脱"的版本作废，可降级为第 1 关的一条 Lore。
- 政治讽刺全力保留（自由资本联合体 / 人民特色资本主义）；只发 Steam 国际区和自己的网站，不考虑国内平台。

## 核心
- 瞬间夺壳是绝对核心；高速射击、跑酷、霓虹电网都为它服务。
- 霓虹电网在**每一关**都存在，三种功能：导轨、节点、意识中继；外观随关卡变（灯管 / 母线 / 光缆 / 供能缆）。

## 世界与关卡
- **12 大关 × 10 区域 = 120 区域**（世界观版的地点顺序）。
- 区域 = 40–90 秒的连续挑战（多个房间/屏幕），区域之间有检查点、自动存档。
- **Demo（M8）= 第 1 关「第十三街地下城」001–010 完整 + Boss「封锁者 / LOCKDOWN」**：
  地下安保镇压机甲，三阶段（夺无人机打探照灯与炮台 → 夺重装机撞断支撑腿 → 电网过载终结），奖励永久能力"远程节点夺壳"。
- 「断轨者 / RAILBREAKER」留给第 5 关「超导运输网络」。

## 表现
- 内部渲染 640×360，整数倍放大；主角约 40 像素高。
- M1–M6 灰盒，配色规则：**青 = 玩家，红 = 敌人，白 = 可夺壳**（永久保留）；M7 再升级为精致霓虹像素风。
- 动画：姿势写在数据表里（`scripts/player/poses.gd`），代码插值，上下半身分层；M7 再加少量逐帧的特殊攻击和处决。

## 操作
- 键鼠为主：WASD 移动，鼠标 360° 瞄准、选择夺壳目标；输入层抽象（`PlayerInput`），手柄后补（约 M4 前后）。
- 没有走路键：按住方向 0.25 秒到疾跑。空格跳；Shift 冲刺（空中 1 次）；**C 滑铲**；贴墙下滑，按住朝墙方向按跳 = 沿同一面墙往上爬（Celeste 式），不按方向 = 蹬开；左键射击（M2）。
- **挥刀固定朝面朝方向**（不看鼠标）：按住 W 上挑，空中按住 S 下劈（命中弹起）。鼠标只管射击和夺壳瞄准。（2026-10-19 用户定）
- 默认高清平滑渲染，F3 可切回 640×360 像素渲染对比（第一次试玩"不丝滑"后改）。
- 土狼时间 + 跳跃缓冲；二段跳是后续解锁能力。

## 系统路线
- 机体（Shell）从 M3 起就带部件状态（武器挂点、肢体），为切割索铺路。
- 高能切割索 SEVER：等 M5 的部件破坏系统稳定后再做；Demo 里放在第 1 关隐藏区，作为可选武器。

## 工程
- `E:\godot\neonraid`，Godot 4.7，GitHub `tntsgdi/NEON-RAID`。
- 从 M1 起中英双语（`scripts/core/i18n.gd`，F2 切换）。
- 测试：headless 脚本输入 + 少量离屏截图，最后由用户亲自试玩；测试绝不读写玩家的设置和存档。
