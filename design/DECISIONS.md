# 设计定案（2026-10-19 grilling）

源文档：Google Drive《霓虹行者 / NEON RAID》2.0。原文由多段对话拼成、前后有矛盾，以本文件为准。

## 作品身份
- 中文《霓虹行者》，英文 **NEON RAID**（不用 NEON RUNNER）。
- 主角 **R-0**：700 年前旧文明的意识转移原型机；现代机器人协议沿用了它的底层，所以能夺壳。
  "企业控制程序逃脱"的版本作废，可降级为第 1 关的一条 Lore。
- 政治讽刺全力保留（自由资本联合体 / 人民特色资本主义）；只发 Steam 国际区和自己的网站，不考虑国内平台。

## 核心
- 瞬间夺壳是绝对核心；高速射击、跑酷、霓虹电网都为它服务。
- 霓虹电网在**每一关**都存在，三种功能：导轨、节点、意识中继；外观随关卡变（灯管 / 母线 / 光缆 / 供能缆）。

## 世界与关卡
- **12 大关 × 10 区域 = 120 区域**（世界观版的地点顺序）。
- 区域 = 40–90 秒的连续挑战（多个房间/屏幕），区域之间有检查点、自动存档。
- **Demo（M8）= 第 1 关「第十三街地下城」001–010 完整 + Boss「封锁者 / LOCKDOWN」**：
  地下安保镇压机甲，三阶段（夺无人机打探照灯与炮台 → 夺重装机撞断支撑腿 → 电网过载终结），奖励永久能力"远程节点夺壳"。
- 「断轨者 / RAILBREAKER」留给第 5 关「超导运输网络」。

## 表现
- 内部渲染 640×360，整数倍放大；主角约 40 像素高。
- M1–M6 灰盒，配色规则：**青 = 玩家，红 = 敌人，白 = 可夺壳**（永久保留）；M7 再升级为精致霓虹像素风。
- 动画：姿势写在数据表里（`scripts/player/poses.gd`），代码插值，上下半身分层；M7 再加少量逐帧的特殊攻击和处决。

## 操作
- 键鼠为主：WASD 移动，鼠标 360° 瞄准、选择夺壳目标；输入层抽象（`PlayerInput`），手柄后补（约 M4 前后）。
- 没有走路键：按住方向 0.25 秒到疾跑。空格跳；Shift 冲刺（空中 1 次）；**C 滑铲**；贴墙下滑，按住朝墙方向按跳 = 沿同一面墙往上爬（Celeste 式），不按方向 = 蹬开；左键射击（M2）。
- **挥刀固定朝面朝方向**（不看鼠标）：按住 W 上挑，空中按住 S 下劈（命中弹起）。鼠标只管射击和夺壳瞄准。（2026-10-19 用户定）
- 默认高清平滑渲染，F3 可切回 640×360 像素渲染对比（第一次试玩"不丝滑"后改）。
- 土狼时间 + 跳跃缓冲；二段跳是后续解锁能力。

## 系统路线
- 机体（Shell）从 M3 起就带部件状态（武器挂点、肢体），为切割索铺路。
- 高能切割索 SEVER：等 M5 的部件破坏系统稳定后再做；Demo 里放在第 1 关隐藏区，作为可选武器。

## 工程
- `E:\godot\neonraid`，Godot 4.7，GitHub `tntsgdi/NEON-RAID`。
- 从 M1 起中英双语（`scripts/core/i18n.gd`，F2 切换）。
- 测试：headless 脚本输入 + 少量离屏截图，最后由用户亲自试玩；测试绝不读写玩家的设置和存档。

## M2 基础战斗（2026-10-19 grilling 定案）
- 基础机体 **3 点血**：被打掉 1 点 + 击退 + 0.6 秒无敌；血空后 0.3 秒内回检查点，不黑屏不加载。
- **冲刺即闪避**：冲刺全程无敌；攻击在冲刺开头 0.12 秒内本该命中 = 精准闪避 → **神经超频**（0.6 秒慢动作、画面泛青、下一击伤害翻倍；M3 起改为夺壳更便宜）。
- **电磁手枪**：左键点射，可见飞行弹约 900 像素/秒、青色拖光；无弹药，8 格能量，停火约 1.2 秒回满；伤害 1（挥刀 2）；开枪时枪臂完全举起、后坐力、枪口火光。
- **轻型安保机**：巡逻，看到玩家 → 0.5 秒红色瞄准线 → 一发慢速红弹（约 260 像素/秒）；4 血，硬直、击退，上挑/重击可打上天空中连击，死亡爆碎。
- **盾兵变体**：正面红色能量盾，子弹从正面打会被弹开；刀砍 3 下破盾；从背后或头上打直接伤本体。
- **刀弹反子弹**：刀的判定碰到敌弹 → 弹回、速度翻倍、变青色，一发打死射手；同时触发神经超频。
- **战斗训练场**：几层平台、3 波敌人，R 重来，F4 在手感测试场和战斗训练场之间切换。
- 音效改用本地 Sonniss GDC 音效库（免版税可商用），`tools/build_sfx.py` 切片生成 `assets/sfx/`；去掉脚步声和起跳声。

## 基础机体形态（2026-10-19 用户定，Jev 选 B 0.58）
- R-0 基础机体改为**反关节（鸟腿）双足机**（`scripts/player/strider_rig.gd`），不再是人形。
  楔形机身天生前倾（疾跑约 40°，弹簧驱动：加速前冲、急停后坐、落地回弹）；两节 IK 反曲腿，跑步有腾空期、触地不打滑；
  右臂就是长刀，平时拖在身后；挥刀 = 15% 回拉蓄力 → 全身扭转劈下并挥过头 20–28° → 收回；背上小炮塔 360° 跟鼠标；背后两条发光线缆按弹簧物理被风拉向身后。
- 依据：疾跑前倾 15–45°、加速度驱动的弹簧倾斜、挥刀短蓄力 + 收势（挥过目标 30–60°）、命中停顿 4–6 帧。

## 速度与动作衔接（2026-10-19，第六次试玩反馈后；Jev 速度选 D 0.82、衔接选 A 0.85）
- 两档速度：跑 340 像素/秒（0.2 秒到顶）；持续全速跑 0.6 秒进入疾驰 430（之后每秒 +300 慢慢顶上去）；急停、反向、撞墙、挨打掉档。冲刺/滑铲超速可叠在疾驰之上缓慢衰减（overspeed_decay 250）。
- 速度感：镜头拉远（跑 6%、疾驰 12%、冲刺再 3%）、进疾驰音爆环 + 风啸 + 镜头一缩、屏幕边缘横向模糊、风声循环随速度、速度线、疾驰残影。
- 动作衔接：惯性化过渡（切换动作时旧脚位与新目标的差按 τ=0.035 秒指数衰减），步幅随速度 48–100 像素，带速度落地时步伐从前脚着地开始。
- 用户定：这是 Demo，最终美术是像素风；现阶段动作流畅、动画质量优先于画面效果。

## M3 瞬间夺壳（2026-10-19 grilling 第 1 轮）
- 沿用文档：按键后 0.1–0.2 秒完成、无黑屏；继承 70% 速度；夺壳后短暂无敌；镜头平滑跟随；意识（PlayerController）与机体（Shell）分离；部件损伤随机体保留。
- Q1 A：M3 机体 = 基础鸟腿机体 + 飞行侦察机（重装机留到 M4）。
- Q2 **C：射程内的敌人随时都能夺**，不需要"控制暴露"。
- Q3 A：软锁定 + 可见准星：离瞄准方向最近、够得着的敌人挂准星；开枪往它修正约 15°（手柄更多）；挥刀时在身边且没按方向就自动转向它；E 夺的也是它。
- Q4 A：E 键（手柄 Y）夺准星目标，距离约 220 像素；超距准星变灰。
- Q5 A：离开的敌人机体断电报废；基础机体单膝跪在原地，可走回去重新夺回；夺来的机体被打坏 → 意识光球弹出，1.5 秒内可飞向附近任意机体（含基础机体）紧急投射，否则回检查点；基础机体被打坏直接回检查点。
- Q6 A：侦察机 = 自由飞行（WASD 八方向、惯性、最高 320、悬停浮动），左键朝鼠标的连射小炮（向下更准），右键短距撞击，Shift 短冲刺，血量 3，不能爬墙/滑铲。
- Q7 A：M3 夺壳不设消耗（Q2 选了随时可夺，精准闪避仍只给神经超频）。
- Q8 A：新建"夺壳训练场"（跳不过的深渊要夺侦察机飞过去、高处平台敌人、失控无人机），F4 三个场地循环。
- **锁敌**：用户反馈"锁敌有点迷"→ 即 Q3 的软锁定准星。
- **走路模式**（用户要求，用户习惯按住 Shift 跑）：不按 Shift = 走（约 150）；**按住 Shift = 跑**（340，持续 0.6 秒进疾驰 430）；**轻点 Shift（0.15 秒内松开）= 冲刺**（松手时触发）。手柄：左摇杆推到底 = 跑，RB 冲刺。
- **按键（用户 2026-10-19）**：J 挥刀、K 开枪、L 冲刺/闪避（轻点 Shift 也是冲刺）；E 夺壳；鼠标左右键保留为备用。纯键盘时开枪打向软锁定目标，无目标则朝面朝方向（按住 W/S 斜上/斜下）。钩锁（M5 切割索）做出来后再定键位。
- M3 第 2 轮：**全部敌人可夺**（枪手、三连发、冲锋机、盾兵、侦察机，各有操作）。
- 台阶（用户反馈卡脚）：36 像素以内的台阶自动迈上、走下时贴地；髋部和脚做平滑过渡。
- **夺壳冷却（2026-10-19 用户定）**：每次夺壳后 0.7 秒冷却，准星上显示冷却进度（外圈弧转满、E 键帽变亮）；冷却中按 E 准星抖一下；意识光球的紧急投射不受冷却限制。
- **墙面行走（2026-10-19 用户："爬墙要如履平地"，此前也提过"能够垂直向上走"）**：碰到墙按住朝墙方向或 W 就沿墙走上去（机体转 90°、脚踩墙面），S 往下，不按方向就扒住不滑，Shift 墙上跑，跑着撞墙时水平速度转成向上速度；空格蹬墙跳不变；到墙顶自动翻上；低于 36 像素的台阶仍是直接迈上。

## 第七次反馈后的定案（2026-10-19，Jev 置信度低交用户定）
- **刀索敌：每一刀都突进**（覆盖此前"挥刀固定朝面朝方向"）：J 时锁定目标在 120 像素内 → 0.06 秒瞬步突进到出刀距离并转向它，刀朝目标实际方向挥（任意角度）；目标更远就原地朝它挥；没有锁定目标时保持原来的面朝方向 / W 上挑 / 空中 S 下劈。
- **UI：精密机械 HUD + 机体呼应**：切角霓虹边框、分段血条 + 白色伤害残影、能量条平滑填充、当前机体名、场地名扫描线擦入、提示滑入滑出、评级卡弹出、设置页展开收起动画；核心灯随血量变色（青→琥珀→红闪），刀刃亮度随连击段数。
- **丝滑**：用"丝滑探针"逐帧找关节跳变并逐个消除；高速转身也做快速翻转，受伤有躯干后仰，待机目镜扫视、炮塔转动。
- 2026-10-19 用户定：先不加"光滑墙"（不可爬材质），所有墙面都能走；深沟/竖井的挑战以后用敌人、机关或夺壳来做，不靠禁爬。
